# Marble world inputs

Photos for `scripts/marble/generate.mjs`, one folder per lot. `worlds/plan.json`
says which files each world uses: `a` is a single photo, `b` is a multi-image
set (up to 8 overlapping shots from one spot, all the same resolution and
orientation). Neither lot has a 360 panorama. Files are the unchanged Drive
originals.

The Google Drive connector can fetch files up to about 5.2 MB. Larger ones
(Warren `IMG_2095`, `2105`, `2111`, `2113`, `2115`, `2117`, `2119`, and
Beaumont `BEAUMONT.mp4`) have to be uploaded here by hand.
