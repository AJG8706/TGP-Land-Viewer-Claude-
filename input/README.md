# Marble world inputs

Photos for `scripts/marble/generate.mjs`, one folder per lot. `worlds/plan.json`
says which files each world uses: `a` is a single listing photo, `b` is a
multi-image set (up to 8 overlapping shots from one spot, all the same
resolution). Neither lot has a 360 panorama.

Upload the originals unchanged (no resizing or cropping) into these folders.
